# 查找、备份与恢复个人数据

安装版把个人数据写在 `HopeCasement.exe` 同一目录。默认安装时，可把 `%LOCALAPPDATA%\HopeCasement` 粘贴到资源管理器地址栏打开。若安装时另选了位置，请查看实际安装目录。源码运行时，数据保存在仓库根目录的 `userdata\`。

| 文件或目录 | 用途 |
| --- | --- |
| `config.json` | 文字样式、纯色、所选背景目录和计划选项。 |
| `quotes.txt` | 个人句库，使用 UTF-8 编码，每行一句。 |
| `backgrounds\` | 默认图片目录。「更换文件夹」选择的其他目录单独存放；当前路径可在「背景图」页确认。 |
| `current_wallpaper.png` | 最近一次生成的壁纸，每次生成都会覆盖。要留住某一张，可将它复制到别处。 |
| `history\` | 勾选「保存每次生成的壁纸」后，按时间存放生成结果，最多保留最近 200 张。使用该选项旁的「打开文件夹」查看。 |
| `error.log` | 自动换图执行异常时，程序会尝试在此追加时间和错误详情。 |

## 卸载或换机前备份

1. 保存需要保留的设置，关闭窗口。在安装目录外新建一个备份文件夹。
2. 复制 `config.json`、`quotes.txt` 和有内容的 `backgrounds\`。如果选择了外部图片目录，换机时也复制其中的照片。
3. 想保留已经合成的壁纸时，另复制 `history\` 和 `current_wallpaper.png`。在备份目录打开一张图片和句库，确认副本可读。

卸载程序会删除安装目录里的配置、句库、默认背景和历史目录、当前壁纸、错误日志，以及旧版可能留下的 `state.json`，同时移除本程序的启动项和间隔、每日任务。安装目录以外自行选择的图片文件夹仍保留。

## 恢复到安装版

1. 安装应用，关闭配置窗口。若新位置已有要保留的个人数据，先另存一份，再将备份内容复制到安装目录下原来的相对位置。
2. 打开应用，在「句子库」核对句数，在「背景图」核对图片数量。外部图片目录换过盘符或位置时，使用「更换文件夹」选回它。
3. 确认计划选项后点「保存设置」，让 Windows 登记这台机器上的触发计划，再点「立即换壁纸」检查效果。[验证自动计划](../scheduling/automatic-changes.md) · [文档索引](../../index.md)
