# 编辑、导入和恢复句子

打开「句子库」，每一行是一条候选句子。程序每次换壁纸时随机选一条，界面中的行号只用来定位。右下角显示当前句数。

## 输入或粘贴

在空白行输入一句话，按 **Enter** 开始下一句。也可以把多行文本直接粘贴到编辑区。光标在编辑区时，按 **Ctrl+S** 可单独保存句库。要看桌面效果，点「立即换壁纸」。句库保留多句时，连续两次也可能抽到同一句。

## 从文本或 Markdown 导入

1. 准备一个 UTF-8 编码的 `.txt` 或 `.md` 文件。例如下面三行会识别出两句。

   ```markdown
   # 今日摘录
   - 今天看见了新的风景。
   - 明天再走一段路。
   ```

2. 点「导入（.txt/.md）」，选择文件。程序跳过空行和 Markdown 标题，去掉常见列表前缀和行内格式，将新内容追加到当前句库。与导入前句库完全相同的句子会跳过。
3. 在「导入完成」对话框核对识别、新增和去重数量；查看编辑区，确认后保存。

## 从文件编辑，或恢复默认句子

「打开文件」会先保存编辑区，再用 Windows 关联的程序打开句库。外部编辑器保存后，如果应用内没有待保存的编辑，句子列表会自动刷新。

「恢复默认句子」会用当前界面语言的预置句子替换编辑区内容。若要保留个人收藏，先备份句库。只想暂时隐藏文字时，在「换壁纸设置」取消「显示文字」即可。[备份与恢复](../data/backup-and-restore.md) · [文档索引](../../index.md)
