# 做出第一张壁纸

这次练习使用全新安装的默认深灰色背景，只留一句「今天看见了新的风景。」。完成后，你可以直接在桌面上读到这句话。已有个人句库时，先保留一份副本。[备份句库和背景](../data/backup-and-restore.md)

1. 在 Windows 10 或 11 上，从项目发布页的 **Assets** 下载安装程序，运行后从开始菜单打开「来日窗笺」。[下载发布版](https://github.com/jc371115833-cmd/hope-casement/releases)
2. 切到「句子库」，选中编辑区里的预置句子，用「今天看见了新的风景。」替换。右下角应显示「共 1 句」。
3. 切到「背景图」，确认「纯色背景」只有默认的 `#2D3033`，并且「图片背景」显示「共 0 张」。这样每次都会抽到同一块深灰色。
4. 切到「换壁纸设置」，勾选「显示文字」。本次只练习手动更换，在「换壁纸计划」下取消三项勾选。
5. 点击窗口底部的「立即换壁纸」。看到「✓ 已更换壁纸」后按 **Win+D** 查看桌面。默认样式下，白色句子位于屏幕靠下的中间。
6. 回到窗口，点「保存设置」。以后打开程序时，背景、样式和手动更换的选择都会保留。

现在可以把自己的照片和更多句子加回去。每次点击「立即换壁纸」都会保存当前句库，并用窗口里选好的样式实际更换桌面。要让以后的定时任务也能使用这些样式，请点「保存设置」。[管理句子](../quotes/manage-quotes.md) · [设置自动更换](../scheduling/automatic-changes.md) · [文档索引](../../index.md)
