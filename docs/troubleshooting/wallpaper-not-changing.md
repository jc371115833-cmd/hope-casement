# 点了「立即换壁纸」，桌面没有变化

先看窗口底部的反馈。「更换中…」表示本次操作还在进行；生成完成并应用到 Windows 后，会短暂显示「✓ 已更换壁纸」。

| 看到什么 | 怎样检查 |
| --- | --- |
| 弹出「没有背景图」 | 到「背景图」核对色块、当前文件夹和「共几张」。若两类候选都为空，添加一种颜色或一张支持格式的图片，再试一次。如果原来有图，请在「打开文件夹」里确认它仍在原处。 |
| 弹出「出错了」 | 记下错误原文和涉及的文件路径。若提示无法读取图片，在资源管理器用照片应用打开该文件；若提示无法写出 PNG，在数据目录查看能否创建普通文件。修正路径、图片或写入权限后再试。 |
| 显示成功，但桌面看起来一样 | 随机选取可能重复。在数据目录打开 `current_wallpaper.png`，核对内容和修改时间；按 **Win+D** 查看实际桌面，若与文件不同，查看 Windows「设置 → 个性化 → 背景」里的当前背景。 |
| 只有背景，看不到句子 | 在「换壁纸设置」勾选「显示文字」，选择与背景反差明显的文字颜色，再点「立即换壁纸」。满意后点「保存设置」。 |
