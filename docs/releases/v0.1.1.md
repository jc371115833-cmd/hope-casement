## 本次更新

- 关闭配置窗口时选择「是」保存，现在会同时更新 Windows 中的换图计划。覆盖安装新版也会保留已有的登录换图项。
- 导入句子时会去除重复行，并识别带 BOM 的 UTF-8 文件。在窗口和外部编辑器里同时修改了句库，保存时会提示冲突。
- 导入同名背景图片时会为新文件追加序号。使用手机照片生成壁纸时，会按照片记录的方向旋转。开启历史记录后，同一秒生成的多张壁纸也能分别保留。
- 自动换图失败时，`--change` 会返回退出码 1，并尝试把错误写入安装目录的 `error.log`，便于排查计划执行失败的原因。

## 从 v0.1.0 升级

关闭来日窗笺，把配置、句库和想保留的图片备份到安装目录之外，然后直接在原位置运行新版安装包。先卸载旧版会删除安装目录中的个人数据，包括默认背景和历史壁纸。升级后可打开「换壁纸设置」核对计划。[备份与恢复手册](https://github.com/jc371115833-cmd/hope-casement/blob/v0.1.1/docs/user-guide/data/backup-and-restore.md)

## 实机验收

桌面是否实际更新，以及 Windows 在用户登录、到达每日时间或设定间隔后能否自动换图，留待专用 Windows 账户验收。[实机验收步骤](https://github.com/jc371115833-cmd/hope-casement/blob/v0.1.1/docs/development/release.md#安装版验收)
